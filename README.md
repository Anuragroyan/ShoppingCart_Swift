🛒 Shopping Cart App

Shopping Cart App is a Swift-based iOS e-commerce application that provides a complete shopping experience with cart management, quantity selection, checkout, favorites, and order history. Firebase is used to store and manage application data, allowing users to maintain their shopping information across the app.

✨ Features

🛍️ Browse and manage products
🛒 Add products to cart
🔢 Select and update product quantity
❤️ Add products to favorites
💳 Checkout
📦 View order history
🔥 Firebase integration
☁️ Cloud-based data storage
📱 Native iOS interface

🔄 Application Process

Browse Products → Select Product → Add to Cart → Adjust Quantity → Review Cart → Checkout → Save Order → View Order History

🛒 Cart Management

Users can add products to their cart and select the required quantity. The cart provides a place to review selected products before proceeding with checkout.

❤️ Favorites

Users can mark products as favorites, making it easier to keep track of products they may want to purchase later.

💳 Checkout & Orders

After reviewing the cart and quantities, users can proceed through the checkout process. Completed orders are stored and can be accessed later through the Order History section.

🔥 Firebase Integration

Firebase is used as the application’s cloud data-storage layer. It manages the data required for products, favorites, cart information, and order history.

🛠️ Tech Stack

Swift – iOS application development
Firebase – Cloud data storage and management
iOS SDK – Native iOS functionality
Shopping Cart – Cart and quantity management
Order Management – Checkout and order history

🎯 Project Purpose

This project demonstrates how to build a practical e-commerce application using Swift and Firebase, covering important shopping workflows such as cart management, favorites, checkout, and order history while working with cloud-based application data.
